# SurveyDataTool

## 测绘数据处理工具

SurveyDataTool 是一个基于 Python 开发的小型测绘数据处理工具。

本项目结合测绘专业知识与 Python 编程，实现常用测量计算、测量点数据读取、批量计算、结果导出以及测量点可视化等功能。

项目主要用于学习 Python 在测绘数据自动化处理中的应用，并逐步完善数据处理、可视化、项目结构和代码组织。

---

# 项目功能

## 1. 基础测绘计算

实现常用测绘计算功能：

- 两点距离计算
- 方位角计算
- 坐标正算
- 坐标反算

### 两点距离计算

根据两个点的平面坐标计算两点之间的距离。

### 方位角计算

根据两个点的坐标计算 A 点到 B 点的方位角。

### 坐标正算

根据：

- 起点坐标
- 距离
- 方位角

计算终点坐标。

### 坐标反算

根据两个点的坐标计算：

- 两点距离
- 两点方位角

---

# 2. 测量点数据处理

支持 CSV 格式的测量点数据读取。

示例数据：

```text
P001,1000.123,2000.456
P002,1050.231,2080.123
P003,1100.442,2030.552
P004,1080.315,1960.742
P005,1020.512,1950.328
```

数据包含：

| 字段 | 说明 |
| --- | --- |
| ID | 测量点编号 |
| X | X 坐标 |
| Y | Y 坐标 |

目前支持：

- CSV 文件读取
- 测量点信息显示
- 根据点号查询测量点
- 获取指定测量点坐标

---

# 3. 批量测量数据计算

支持多个测量点自动进行计算。

例如：

```text
P001
P002
P003
P004
P005
```

程序会按照测量点顺序自动计算：

```text
P001-P002
P002-P003
P003-P004
P004-P005
```

计算内容：

- 两点距离
- 两点方位角

计算结果自动保存到：

```text
output/result.csv
```

---

# 4. 测量点可视化

使用 `matplotlib` 对测量点进行可视化。

程序可以：

- 绘制测量点
- 标注测量点编号
- 按照测量点顺序连接测量点
- 显示 X、Y 坐标轴
- 显示网格
- 将结果保存为 PNG 图片

生成的图片：

```text
output/survey_points.png
```

示例流程：

```text
data/points.csv
    ↓
读取测量点
    ↓
提取 X、Y 坐标
    ↓
绘制测量点
    ↓
标注点号
    ↓
连接测量点
    ↓
保存 survey_points.png
```

# 5. 基础异常处理

对用户输入和文件读取增加了基础异常处理。

## 数字输入异常

当用户输入非数字内容时：

```text
请输入A点X坐标：abc
```

程序不会直接崩溃，而会提示：

```text
输入错误！请输入数字。
```

并要求重新输入。

使用 `try-except` 捕获 `ValueError`。

---

## CSV 文件异常

当用户输入不存在的 CSV 文件时：

```text
请输入CSV文件名：abc.csv
```

程序会提示：

```text
文件不存在！请检查文件名。
```

并返回主菜单。

使用 `try-except` 捕获 `FileNotFoundError`。

# 数据目录

项目对输入数据和输出结果进行了分类管理。

## data

用于存放程序输入数据。

例如：

```text
data/points.csv
```

## output

用于存放程序运行产生的结果。

例如：

```text
output/result.csv
output/survey_points.png
```

通过将输入数据和输出结果分开管理，使项目目录更加清晰，也便于后续扩展和维护。

# 使用方法

## 1. 安装依赖

本项目主要使用 Python 标准库，并使用 matplotlib 进行数据可视化。

安装 matplotlib：

```bash
pip install matplotlib
```

---

## 2. 准备数据

将测量点 CSV 文件放入：

```text
data/
```

例如：

```text
data/points.csv
```

---

## 3. 运行程序

在项目根目录运行：

```bash
python main.py
```

---

## 4. 功能菜单

```text
================================
       SurveyDataTool
       测绘数据处理工具
================================

1. 两点距离
2. 方位角
3. 坐标正算
4. 坐标反算
5. 读取测量点数据
6. 测量点距离及方位角
7. 批量计算测量点数据
8. 测量点可视化
0. 退出
```

输入对应数字即可选择功能。

当需要读取 CSV 文件时，只需要输入文件名，例如：

```text
points.csv
```

程序会自动从：

```text
data/points.csv
```

读取数据。
