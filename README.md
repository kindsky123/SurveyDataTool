# SurveyDataTool

## 测绘数据处理工具

SurveyDataTool 是一个基于 Python 开发的小型测绘数据处理工具。

本项目结合测绘专业知识与 Python 编程，实现了常用测量计算、测量点数据读取、批量计算以及结果导出等功能。

项目目标是实现测绘数据处理流程的自动化，提高测量数据处理效率。

---

# 项目功能

## 1. 基础测绘计算

实现常用测绘计算功能：

- 两点距离计算
- 方位角计算
- 坐标正算
- 坐标反算


### 两点距离计算

根据两个点的平面坐标：

```
A(X1,Y1)
B(X2,Y2)
```

计算两点之间的空间距离。


### 方位角计算

根据两个点的坐标关系，计算 A 点到 B 点的方位角。


### 坐标正算

根据：

- 起点坐标
- 边长距离
- 方位角

计算目标点坐标。


### 坐标反算

根据两个测量点坐标：

计算：

- 两点距离
- 两点方位角

---

# 2. 测量点数据处理

支持 CSV 格式测量数据读取。

示例：

```
P001,1000.123,2000.456
P002,1050.231,2080.123
P003,1100.442,2030.552
P004,1080.315,1960.742
P005,1020.512,1950.328
```

数据格式：

|字段|说明|
|-|-|
|ID|测量点编号|
|X|X坐标|
|Y|Y坐标|

实现功能：

- CSV 文件读取
- 测量点信息显示
- 根据点号查询测量点
- 获取指定点坐标数据

---

# 3. 批量测量数据计算

支持多个测量点自动处理。

例如输入：

```
P001
P002
P003
P004
P005
```

程序自动计算：

```
P001-P002
P002-P003
P003-P004
P004-P005
```

计算内容：

- 两点距离
- 两点方位角

计算结果自动保存：

```
result.csv
```

结果示例：

|起点|终点|距离|方位角|
|-|-|-|-|
|P001|P002|95.095|57.123|
|P002|P003|61.234|...|
