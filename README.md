# SurveyDataTool

## 测绘数据处理工具

SurveyDataTool 是一个基于 Python 开发的小型测绘数据处理工具。

本项目结合测绘专业知识与 Python 编程，实现常用测量计算、测量点数据读取、批量计算、结果导出、测量点可视化、数据统计、导线测量计算、计算报告导出以及单元测试等功能。

项目主要用于学习 Python 在测绘数据自动化处理中的应用，并逐步完善数据处理、可视化、项目结构和代码组织。


## 项目功能

### 1. 基础测绘计算

实现常用测绘计算功能：

- 两点距离计算
- 方位角计算
- 坐标正算
- 坐标反算

#### 两点距离计算

根据两个点的平面坐标计算两点之间的距离。

#### 方位角计算

根据两个点的坐标计算 A 点到 B 点的方位角（0°~360°）。

#### 坐标正算

根据起点坐标、距离、方位角计算终点坐标。

#### 坐标反算

根据两个点的坐标计算两点距离和两点方位角。


### 2. 测量点数据处理

支持 CSV 格式的测量点数据读取。

**CSV 文件格式要求：**

| 列名 | 说明 |
| --- | --- |
| 点号 | 测量点编号 |
| X | X 坐标 |
| Y | Y 坐标 |

示例数据：

```csv
点号,X,Y
P001,1000.123,2000.456
P002,1050.231,2080.123
P003,1100.442,2030.552
P004,1080.315,1960.742
P005,1020.512,1950.328
```

**数据校验功能：**

- 检查 CSV 文件是否包含必需的列（点号、X、Y）
- 检查坐标值是否为有效数字
- 检查点号是否重复
- 检查点号是否为空
- 空文件或只有表头的文件会被检测并提示

目前支持：

- CSV 文件读取与校验
- 测量点信息显示
- 根据点号查询测量点
- 获取指定测量点坐标


### 3. 批量测量数据计算

支持多个测量点自动进行计算。

**功能特点：**

- 自动显示计算进度（当前第 N/总共 M 对点）
- 自动累计边长，并输出到结果文件中
- 结果自动保存为 CSV 文件

程序会按照测量点顺序自动计算相邻点对：

```text
P001-P002
P002-P003
P003-P004
P004-P005
```

计算内容：

- 两点距离
- 两点方位角
- 累计边长

计算结果自动保存到：

```text
output/result.csv
```

**输出示例：**

```csv
起点,终点,距离,方位角,累计边长
P001,P002,94.115,57.831,94.115
P002,P003,70.558,315.367,164.673
P003,P004,72.654,253.917,237.327
P004,P005,60.703,189.878,298.030
```


### 4. 测量点可视化

使用 `matplotlib` 对测量点进行可视化。

**功能特点：**

- X/Y 坐标轴等比例（测区形状真实不变形）
- 点之间带方向箭头（显示导线走向）
- 点号自动偏移标注（避免重叠遮挡）
- 显示网格和图例
- 保存为 PNG 图片

生成的图片：

```text
output/survey_points.png
```


### 5. 测量点统计

对测量点数据进行统计分析，输出：

- 点数量
- X 坐标范围（最小值、最大值）
- Y 坐标范围（最小值、最大值）
- X 坐标平均值
- Y 坐标平均值

适用于快速了解测区范围和数据整体情况。


### 6. 导线测量计算

实现闭合导线坐标推算、闭合差计算、平差与报告导出。

**功能特点：**

- 从 CSV 文件读取导线观测数据（转角、边长）
- 支持设置已知点（不参与计算，仅作标记）
- 逐点推算导线点坐标
- 计算坐标闭合差 fx、fy
- 计算全长闭合差 f
- 计算相对闭合差 K = f / Σ边长
- 按边长比例反号分配闭合差（平差）
- 精度评定（自动判断 K ≤ 1/2000 是否合格）
- **导出计算报告到 .txt 文件**（`output/` 目录）

**导线观测数据 CSV 格式：**

```csv
点号,角(度),边长(米),备注
B,120.5,100.0,
C,95.3,85.5,
D,110.8,92.0,
E,133.2,78.5,
```


### 7. 异常处理

#### 数字输入异常

当用户输入非数字内容时，程序不会崩溃，会提示重新输入。

#### CSV 文件异常

- 文件不存在 → `文件不存在！请检查文件名。`
- CSV 缺少必需列 → `数据格式错误：CSV缺少必需列：['点号']`
- 坐标值不是数字 → `数据检查失败：测量点 P001 的X坐标不是数字！`
- 点号重复 → `数据检查失败：测量点 P001 重复！`
- 文件为空或只有表头 → `数据检查失败：文件中没有测量点数据！`

#### 顶层异常捕获

程序主循环包含顶层 `try/except`，任何未被捕获的意外错误都会被拦截并提示，程序不会直接闪退。


### 8. 单元测试

使用 Python 自带的 `unittest` 框架，为核心功能提供自动化测试。

**测试覆盖：**

| 测试文件 | 测试内容 |
|---|---|
| `test_surveying.py` | 距离、方位角、坐标正算、坐标反算 |
| `test_data_process.py` | CSV读取、数据校验、统计 |
| `test_traverse.py` | 导线推算、平差 |

运行测试：

```bash
python -m unittest discover -v
```

## 使用方法

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 准备数据

将测量点 CSV 文件放入 `data/` 目录。

### 3. 运行程序

```bash
python main.py
```
