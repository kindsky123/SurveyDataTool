# SurveyDataTool

一个基于 Python 开发的测绘数据处理与计算工具。

## 项目简介

SurveyDataTool 是一个面向测绘学习与实践的 Python 项目，
用于实现测绘工程中的常用计算，并逐步扩展数据处理、
可视化和坐标转换等功能。

本项目在学习开源地理空间项目的基础上进行学习和实践，
核心功能由本人独立实现。

## 当前功能

### 测绘计算

- [x] 两点距离计算
- [x] 方位角计算
- [x] 坐标正算
